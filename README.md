
# NutriAI — Asisten Gizi Makanan

NutriAI adalah proyek website edukasi gizi makanan
yang dibuat sebagai sarana belajar pengembangan web.

## Fitur
- Pencarian makanan
- Informasi nutrisi per 100 gram
- Kalkulator total nutrisi berdasarkan porsi
- Inspirasi menu sederhana
- Tampilan responsif

## Teknologi
- HTML
- CSS
- JavaScript
- GitHub Pages

## Cara Menjalankan
1. Unduh atau clone repository.
2. Buka folder proyek di Visual Studio Code.
3. Jalankan index.html menggunakan Live Server
   atau buka langsung melalui browser.

## Sumber Data
Data nutrisi versi demonstrasi menggunakan angka contoh.
Untuk versi publik, data harus diverifikasi dan sumbernya
dicantumkan secara jelas.
